# Plataforma de Análisis y Monitoreo de Riesgos del Perú

Plataforma web para analizar riesgos epidemiológicos y climáticos,
identificar zonas prioritarias y facilitar la toma de decisiones preventivas.

## Tecnologías

- Frontend: React
- Backend: Python + Flask
- Control de versiones: Git y GitHub

## Módulos

1. Panel principal
2. Análisis epidemiológico
3. Análisis climático
4. Análisis territorial
5. Evaluación de establecimientos
6. Predicciones y alertas
7. Informes y reportes
8. Datos y metodología
